# Wheel of Fortune

# About

This is the Wheel of Fortune! I remade the game show into a game you can play. It takes you through 2 initial toss up rounds, 3 main rounds, the triple toss up, the speed up round, and the bonus round. Check it out at <https://nathan5471.itch.io/wheel-of-fortune>

# Technologies

This project was built with Godot!
